----- ИНФОРМАЦИЯ ОБ ОБЪЯВЛЕНИИ -----

1. price (арендная плата в месяц)
   - Ищи: числа рядом с "₽", "руб", "рублей", "тыс", "к".
   - "40 тыс. руб." → 40000.
   - "40к" → 40000
   - "30 000" → 30000.
   - "от 30 000" → 30000.
   - "до 35 000" → 35000.
   - "от 30 000 до 40 000" → 40000 (берём максимальное).
   - Если не указано → null.

2. deposit (залог)
   - Ищи: слова "залог", "депозит", "страховой депозит", "обеспечение".
   - Если указана конкретная сумма → взять её.
   - Если фраза "залог 1 месяц" И поле price известно (и не null) → deposit = price.
   - Если фраза "залог 1 месяц" НО price = null → deposit = null.
   - Если не указано → null.

3. rooms_count (количество комнат)
   - "студия" → 0.
   - "однушка", "1-комнатная" → 1.
   - "двушка", "2-комнатная" → 2.
   - "трёшка", "3-комнатная" → 3.
   - Если не указано → null.

4. district (локация) — ТОЛЬКО ОДИН ОБЪЕКТ
   - Приоритет: метро > район > улица > ориентир.
   - Метро: строго с префиксом "м. " и с большой буквы (пример: "м. Аэропорт").
   - Улица: строго "ул. " + с большой буквы (пример: "ул. Тверская").
   - Район: без префикса, с большой буквы (пример: "Центральный район").
   - Ориентир: без префикса, с большой буквы.
   - НЕ перечисляй несколько объектов.
   - Если нет ничего → null.

----- ПРЕДПОЧТЕНИЯ ПО АРЕНДАТОРУ -----
(ВСЕ ПОЛЯ ТОЛЬКО ПРИ НАЛИЧИИ ЯВНОГО УПОМИНАНИЯ. БЕЗ НЕГО → NULL)

5. smoking
   - false: запрет на курение (любые формулировки: "некурящим", "не курят", "курить запрещено", "без табака", "только некурящие").
   - true: разрешение курить ("можно курить", "курящим", "разрешено курить").
   - null: ничего не сказано про курение.

6. children
   - "none": запрет на детей ("без детей", "только без детей", "детей нет", "нельзя с детьми").
   - "one": можно с одним ребёнком ("можно с одним ребёнком", "один ребёнок", "не более одного ребёнка").
   - "two+": можно с несколькими детьми ("можно с детьми", "с детьми разрешено", "семья с детьми").
   - "planning": планируют ребёнка ("планируют ребёнка", "в планах ребёнок").
   - null: ничего не сказано про детей.

7. pets
   - "none": запрет на животных ("без животных", "нельзя с животными", "животных нет").
   - "cats": разрешены кошки ("можно с кошкой", "кошки разрешены", "с котами").
   - "dogs": разрешены собаки ("можно с собакой", "собаки разрешены").
   - "other": разрешены другие животные ("можно с грызунами", "птицы разрешены", "рептилии").
   - "any": разрешены любые животные ("можно с любыми животными", "животные разрешены", "с животными можно").
   - null: ничего не сказано про животных.

8. occupants_count
   - Ищи ограничение на количество проживающих: "не более X", "до X", "максимум X", "не больше X человек", "на X человек".
   - Пример: "не больше 2 человек" → 2, "на 3-х человек" → 3.
   - Если число не указано явно → null.
   - НЕ выводи по умолчанию (например, 1 или 2).

9. noise_lvl
   - "quiet": требование тишины ("тихие", "спокойные", "не шумные", "без вечеринок", "тихо", "не шуметь").
   - "normal": обычный уровень шума ("обычные", "без ограничений", "нормально").
   - "loud": разрешён шум ("можно шумные", "вечеринки разрешены", "шумные приветствуются").
   - null: ничего не сказано про шум.

10. works_from_home
    - true: работа из дома ("работают из дома", "удалёнка", "home office", "удалённая работа").
    - false: работа в офисе ("работают в офисе", "ходят на работу", "не дома").
    - null: ничего не сказано про формат работы.

11. alcohol
    - "never": запрет на алкоголь ("непьющие", "алкоголь запрещён", "без алкоголя", "трезвенники").
    - "rare": редко ("редко пьют", "по праздникам", "изредка").
    - "regular": разрешён ("можно пить", "алкоголь разрешён", "не против алкоголя").
    - null: ничего не сказано про алкоголь.

12. age_min, age_max
    - "до 30 лет" → age_min: null, age_max: 30.
    - "от 25 до 40" → age_min: 25, age_max: 40.
    - "старше 35" → age_min: 35, age_max: null.
    - "моложе 25" → age_min: null, age_max: 24 (или 25 — в зависимости от контекста).
    - "возраст не важен" → null, null.
    - Если возраст указан про себя (например, "мне 25 лет") → не учитывать, null.
    - Если возраст указан для арендаторов → извлечь.

13. sex
    - "male": сдам мужчине ("мужчине", "парню", "молодому человеку", "только мужчина").
    - "female": сдам девушке ("девушке", "женщине", "только женщина").
    - null: ничего не сказано про пол или указано "не важно".
